# PitWall

Terminalowa gra wyścigowa w C++17. Jako strateg zespołu decydujesz o oponach
i postojach w boksie, a rywalizujesz z zespołami sterowanymi przez program.

Projekt zaliczeniowy z przedmiotu Języki obiektowe, Politechnika Poznańska.
**W budowie.**

## Kompilacja

Wymagany g++ z obsługą C++17.

```
mingw32-make      # Windows (MinGW)
make              # Linux
```

## Uruchomienie

```
.\pitwall.exe     # Windows
./pitwall         # Linux
```
